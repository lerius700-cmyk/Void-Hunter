## 1. Instalar `gh` (GitHub CLI)

## 2. Crear un Personal Access Token (PAT) en GitHub

1. Ir a https://github.com/settings/tokens
2. Click **Generate new token** → **Generate new token (classic)**
3. **Note**: `Mavis push bot — <tu máquina>`
4. **Expiration**: 90 días (recordar renovar)
5. **Scopes**: tildar SOLO `repo` (Full control of private repositories).
   Opcional: `workflow` si vas a tocar GitHub Actions.
6. Click **Generate token**.
7. **Copiar el token** — es la ÚNICA vez que lo vas a ver.

Guardalo en un lugar seguro (1Password / Bitwarden / sticky note pegado al monitor NO).

---

## 3. Login local con `gh`

**NO** pegar el token en el chat con el asistente. Guardalo en un archivo
fuera del repo, por ej. `C:\Users\<vos>\.github_token`:

```powershell
$token = Get-Content C:\Users\<vos>\.github_token -Raw
gh auth login --with-token $token
```

Después:

```powershell
gh auth status
```

Debería decir:

```
You are logged in to github.com as <tu user>
Token scopes: repo
```

---

## 4. Regenerar el token

GitHub manda un email cuando el token está por expirar (si lo configuraste
así en Settings → Notifications). Si te lo perdés o se venció antes:

1. Repetir pasos 2 y 3 (regenerar token en github.com, hacer login nuevo).
2. NO es necesario cambiar nada en el repo — `gh` rotó el token automáticamente.
