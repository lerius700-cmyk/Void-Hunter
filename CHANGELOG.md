## [v1.1.0] — 2026-08-18

> Pixel art nebulae + bomb VFX + 50 choreographed enemy patterns.

### Added

**BLOQUE 58.14.6 — Pixel art nebulae**
- New `Assets/background/galaxy_pixelart_*.png` (4 tinted variants: blue,
  red, cyan, violet) generated by `tools/tint_galaxy_sprites.py` (HSL
  hue rotation, preserves saturation/lightness for chunky pixel art).
- Parallax now uses these pixel art sprites instead of the old AI high-res
  galaxies. NEAREST scaling preserves the chunky aesthetic.
- Gameplay uses 4 nebulas (was 2) with `nebula_radius 60-90`.

**BLOQUE 58.14.7 — Bomb VFX**
- New `src/fx/bomb_burst.py`: 3 concentric soft rings (yellow → orange
  → red-orange), 0.4s life, scale + fade animation.
- Wired in `src/ui/gameplay_runtime.py` (trigger on bomb, update each
  frame, draw after shockwave).

**BLOQUE 58.14.7 — 50 choreographed enemy patterns**
- New `src/systems/wave_patterns/composed.py`: 9 formations × 8 bezier
  paths × 3 follow modes × counts 4-8 = 50 combinations.
- Each `ComposedPattern.generate()` outputs a `WavePatternResult` with
  `extra={segments, segment_durations, formation, path, follow}` in
  the format `runtime.py` reads via `attach_multi_segment_path`.
- New `SoloEnemySpawner`: 1 red solo ship every 5s, with a slight curve
  path. Independent of pattern timing for ambient variety.

**BLOQUE 58.14.7 — Manager wire**
- `WavePatternKind.COMPOSED = "composed"` added to the enum.
- `ProceduralWaveManager._composed_patterns: list[WavePattern]` added.
- `register_composed_patterns()` method: registers all 50 in one call.
- `pick_pattern()` handles kind=COMPOSED by `rng.choice` from the pool
  (graceful fallback to BEZIER_SWEEP if pool is empty).
- COMPOSED added to weighted pool at 20/24/28 per floor (highest
  single weight), so the 50 patterns get meaningful screen time
  (~18% of picks in smoke test).
- `GameplayRuntime.enable_procedural_patterns()` now calls
  `register_composed_patterns()` and instantiates `SoloEnemySpawner`.
- `GameplayRuntime._spawn_procedural_patterns()` ticks the solo
  spawner and spawns the returned ships.
- New `src/systems/wave_patterns/runtime.py::spawn_solo_ship()` helper.

**BLOQUE 58.14.8 follow-up — Variety from your reference**
- 4 pixel art galaxy tints (blue, red, cyan, violet) generated from the
  user's wave intro reference (`galaxy_pixelart_reference.png`).
- `tools/extract_galaxy_sprite.py`: reproducible crop + transparency.
- `tools/tint_galaxy_sprites.py`: reproducible HUE shift generator.

### Changed
- `src/systems/parallax.py`: `_GALAXY_SPRITE_PATHS` now points to 4
  pixel art variants. NEAREST scaling, aspect ratio preserved, no
  circular mask (transparent background handles edges).
- `src/ui/gameplay_runtime.py`: nebula_count 2→4, radii 80-110→60-90.
- `tests/test_bloque_58_10.py`, `tests/test_wave_patterns.py`: updated
  pool count expectations (6→7) and added `mgr.register_composed_patterns()`
  to picking tests so COMPOSED is actually pickable.

### Fixed
- 5 pre-existing test failures (audio SFX count + lowpass WAV) that
  had been silently broken in earlier sessions — now all 1171 tests
  pass.
- The `.build-venv` was missing `numpy`, which the lowpass test needs.
  Fixed by `tools/setup_build_venv.bat`.

### Verified
- Smoke test (`tools/smoke_test_composed_wire.py`): all 6 tests pass.
  500 picks: COMPOSED = 89 (18%), all with valid segments.
- Full pytest: 1171/1171 (was 1166/1171).
- In-game visual: `release/topmost_225135_8.png` shows
  `PATTERN: COMPOSED` in the HUD, all 4 galaxy tints visible, solo
  enemy red ship spawning, bomb VFX (orange ring) on B key.
